# BlackSea Connect UX Terminology

Use these user-facing terms in Bulgarian first, with matching English, French, and Russian where the language exists.

| Internal / old term | Bulgarian | English | French | Russian |
| --- | --- | --- | --- | --- |
| Operation / Operations | Задача / Задачи | Task / Tasks | Tâche / Tâches | Задача / Задачи |
| Mission Control | Контролен център | Control center | Centre de contrôle | Контрольный центр |
| Dispatcher | Разпределяне на задачите | Task assignment | Répartition des tâches | Распределение задач |
| Timeline | История / Списък със задачи | History / Task list | Historique / Liste des tâches | История / Список задач |
| Workflow | Стъпки / Начин на работа | Steps / Way of working | Étapes / Façon de travailler | Шаги / Порядок работы |
| Quick Create | Нова задача | New task | Nouvelle tâche | Новая задача |
| Professional | Изпълнител | Service provider | Prestataire | Исполнитель |
| Evidence | Снимки и документи | Photos and documents | Photos et documents | Фото и документы |
| Status | Състояние | Status | Statut | Состояние |
| Priority | Спешност | Urgency | Urgence | Срочность |
| SLA | Срок за изпълнение | Deadline | Délai | Срок |
| Dashboard | Табло | Dashboard | Tableau de bord | Панель |
| Overview | Обобщение | Summary | Résumé | Обзор |

Avoid showing internal identifiers, route names, database enum names, or unexplained abbreviations to normal users.
